# Learning Log

Use this file to track what each build phase teaches.

## Phase 1: Scaffold

What this phase teaches:

- How frontend and backend folders are separated
- Why APIs use request and response schemas
- Why agents should return structured data
- How a safety review can sit between agent output and the user

## Phase 2: Model Integration

Planned learning:

- How prompts become implementation details behind typed contracts
- How model outputs are validated
- How fallback behavior works when an AI call fails

## Phase 3: Evals

Planned learning:

- How to test deterministic calculators
- How to test routing
- How to test safety behavior
- How to track regressions over time
